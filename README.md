# Aflora (demonstração)

> Cultive boas atitudes. Colha conquistas.

Versão de demonstração da Aflora, a plataforma de engajamento e recompensas da Conexão.
Roda inteira no navegador: não tem servidor nem banco de dados, e os dados de teste ficam
salvos só no navegador de quem abre. O selo "Demonstração", no canto da tela, troca de perfil
e restaura os dados de exemplo.

Perfis para testar: colaborador (Mauricio), administradora (Carla), aprovadora (Ana) e
RH local de Paraty (Roberta).

## Publicar no GitHub Pages

1. Crie um repositório público, por exemplo `aflora`.
2. Envie `index.html`, `favicon.svg`, `.nojekyll` e este `README.md` para a raiz.
3. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
4. Em um ou dois minutos o endereço fica `https://SEU-USUARIO.github.io/aflora/`.
